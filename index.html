Map notes & controls

This atlas uses the actual map tiles and named areas in the Wheezel Crimson Grid fork.

  • Drag to pan; scroll or pinch to zoom. Arrow keys pan, +/− zoom, F fits the layer.
  • Click a marker to follow its linked destination. The destination stays at the same screen position, at the same zoom. Use Back to return.
  • Elevators and ladders with several destinations show a destination list.
  • Manual layer changes preserve your coordinates and zoom.
  • Gray markers are one-way exits or unresolved links; the atlas does not invent destinations.

Labels come from map area definitions. Z numbers and coordinates are local to the map files; the live server can add coordinate offsets. This is a static atlas: locked doors, elevator availability, randomly spawned content and in-round changes are not simulated.

Stair landings are derived from stair direction, the end of each stair chain, and the next level's turf. Umbra exits retain the source's one-way rules. Elevator links show mapped call stops.
